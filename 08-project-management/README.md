# 08 - Project Management

Modul ini memandu tata kelola proyek perangkat lunak: penyusunan piagam proyek (charter), perencanaan sprint, estimasi beban kerja, mitigasi risiko, pencatatan keputusan, dan peninjauan stage-gate.

## Dokumen dalam Modul Ini:
1. [Project Charter](project-charter.md) - Mandat resmi pembentukan proyek dan batasan ruang lingkup.
2. [Project Planning](project-planning.md) - Struktur rincian kerja (WBS) dan penyusunan roadmap.
3. [Estimation and Prioritization](estimation-and-prioritization.md) - Story points, planning poker, dan velocity.
4. [Risk Register](risk-register.md) - Identifikasi, penilaian dampak/probabilitas, dan rencana mitigasi risiko.
5. [Decision Log](decision-log.md) - Pencatatan keputusan operasional dan manajerial proyek.
6. [Change Log](change-log.md) - Pengendalian perubahan ruang lingkup dan penyesuaian jadwal.
7. [Project Status Report](project-status-report.md) - Format laporan berkala bagi para pemangku kepentingan.
8. [Stage-Gate Process](stage-gate-process.md) - Titik evaluasi kelayakan antar-fase proyek.
