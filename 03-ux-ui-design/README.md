# 03 - UX/UI Design

Modul ini menetapkan standar perancangan pengalaman pengguna (UX) dan antarmuka visual (UI) agar produk intuitif, konsisten, mudah diakses, dan siap diimplementasikan oleh tim developer.

## Dokumen dalam Modul Ini:
1. [Information Architecture](information-architecture.md) - Struktur navigasi dan hierarki konten.
2. [User Flows](user-flows.md) - Pemetaan alur perjalanan langkah-demi-langkah pengguna.
3. [Wireframes and Prototypes](wireframes-and-prototypes.md) - Dari lo-fi hingga prototype interaktif.
4. [UI Specification](ui-specification.md) - Detail layout, grid, spacing, dan anotasi serah-terima pengembang.
5. [Design System](design-system.md) - Pengelolaan token desain, tipografi, warna, dan komponen visual.
6. [UI States and Error Messages](ui-states-and-error-messages.md) - Penanganan state antarmuka (loading, empty, error, success).
7. [Accessibility and Responsive Design](accessibility-and-responsive-design.md) - Standar WCAG 2.1 AA dan desain adaptif multi-layar.
