# 01 - Project Discovery

Fase penemuan proyek (discovery) berfokus pada memahami akar masalah bisnis, kebutuhan pengguna, pemangku kepentingan kunci, serta menganalisis kelayakan sebelum solusi teknis dibangun.

## Dokumen dalam Modul Ini:
1. [Problem Discovery](problem-discovery.md) - Teknik identifikasi masalah (5 Whys, Problem Statement Canvas).
2. [Stakeholder Analysis](stakeholder-analysis.md) - Pemetaan stakeholder, matriks kekuasaan/minat, dan RACI.
3. [User Research](user-research.md) - Wawancara pengguna, persona, dan journey mapping.
4. [Assumptions and Constraints](assumptions-and-constraints.md) - Asumsi bisnis/teknis dan batasan regulasi/anggaran.
5. [Feasibility Analysis](feasibility-analysis.md) - Penilaian kelayakan teknis, ekonomi, dan operasional.
6. [Discovery Exit Criteria](discovery-exit-criteria.md) - Kriteria gerbang keluar untuk melangkah ke fase requirements.
