# 07 - Delivery and Operations

Modul ini menguraikan praktik penyebaran (*deployment*), otomatisasi CI/CD, keandalan operasional, migrasi database tanpa downtime, serta respons insiden produksi.

## Dokumen dalam Modul Ini:
1. [Environment Strategy](environment-strategy.md) - Pengelolaan lingkungan Dev, Staging, UAT, dan Produksi.
2. [CI/CD](ci-cd.md) - Pipeline otomatisasi pengujian, build, dan continuous delivery.
3. [Deployment Guide](deployment-guide.md) - Pola deployment Blue-Green, Canary, dan Rolling Updates.
4. [Release Management](release-management.md) - Manajemen versi (SemVer), changelog, dan release notes.
5. [Database Migration and Rollback](database-migration-and-rollback.md) - Migrasi skema tanpa downtime (Expand & Contract).
6. [Backup and Recovery](backup-and-recovery.md) - Target RPO, RTO, dan prosedur drill pemulihan bencana.
7. [Monitoring and Observability](monitoring-and-observability.md) - Tiga pilar observabilitas (Logs, Metrics, Traces).
8. [Incident Response](incident-response.md) - Tingkat keparahan insiden (SEV-1 s.d SEV-4) dan alur post-mortem.
9. [Release Readiness](release-readiness.md) - Daftar verifikasi kelayakan sebelum proses rilis produksi.
