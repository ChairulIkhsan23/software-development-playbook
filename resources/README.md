# Sumber Daya & Referensi Pendukung

Folder ini memuat kurasi sumber daya eksternal terpercaya, standar industri formal, rekomendasi buku, kursus terbuka, dan perangkat lunak bantu untuk memperluas pemahaman teknis di luar materi playbook ini.

---

## 1. Daftar Berkas Referensi

- [`standards-and-frameworks.md`](./standards-and-frameworks.md) — Katalog standar resmi internasional (ISO/IEC/IEEE 12207, ISO 29148, ISO 25010, OWASP Top 10, WCAG 2.1 AA, RFC 7807, The Twelve-Factor App, SemVer, Conventional Commits).
- [`recommended-books.md`](./recommended-books.md) — Rekomendasi buku fundamental pilihan industri rekayasa perangkat lunak (*Clean Code*, *The Pragmatic Programmer*, *Refactoring*, *Designing Data-Intensive Applications*, *Building Microservices*, *Accelerate*, *Site Reliability Engineering*).
- [`recommended-courses.md`](./recommended-courses.md) — Kursus terbuka berkualitas universitas dan industri (CS50x, MIT Missing Semester, Full Stack Open, Testing JavaScript, System Design Primer, PortSwigger Web Security Academy).
- [`useful-tools.md`](./useful-tools.md) — Daftar utilitas dan kakas pendukung produktivitas (Mermaid, Excalidraw, Bruno, Scalar, k6, Biome, Gitleaks, Trivy, Prometheus, Grafana, OpenTelemetry, Docker).

---

## 2. Kebijakan Kurasi Referensi

1. **Akurasi & Verifikasi**: Seluruh referensi yang dicantumkan merupakan karya atau standar nyata yang telah diverifikasi judul, penulis, dan institusi penerbitnya. Repositori ini tidak memuat judul buku atau kursus fiktif.
2. **Kesesuaian Konteks**: Tidak semua standar atau kakas wajib digunakan pada setiap proyek. Gunakan tabel panduan pemilihan pada masing-masing dokumen untuk menentukan kakas yang proporsional bagi skala proyek Anda.
