# 04 - Technical Design

Modul ini memandu perancangan sistem backend, frontend, arsitektur basis data, protokol API, aspek keamanan, dan persyaratan non-fungsional.

## Dokumen dalam Modul Ini:
1. [System Architecture](system-architecture.md) - Arsitektur level tinggi dan diagram C4 Model.
2. [Architecture Patterns](architecture-patterns.md) - Monolith, Microservices, Clean Architecture, Event-Driven.
3. [Architecture Decision Records (ADR)](architecture-decision-records.md) - Format dan tata kelola pencatatan keputusan arsitektural.
4. [Database Design](database-design.md) - Pemodelan data relasional, NoSQL, normalisasi, dan indexing.
5. [Data Dictionary](data-dictionary.md) - Katalog atribut data, tipe data, dan konstrain integritas.
6. [API Design](api-design.md) - Panduan RESTful API, penamaan sumber daya, dan pagination.
7. [API Error Handling](api-error-handling.md) - Standar penanganan error dan format RFC 7807 Problem Details.
8. [Authentication and Authorization](authentication-and-authorization.md) - OAuth 2.0, JWT, RBAC, dan ABAC.
9. [Non-Functional Requirements](non-functional-requirements.md) - Standar performa, skalabilitas, dan ketersediaan tinggi.
10. [Security and Privacy](security-and-privacy.md) - Pencegahan OWASP Top 10, enkripsi, dan kepatuhan privasi data.
11. [Integration Design](integration-design.md) - Webhook, komunikasi asinkron, retry, dan circuit breaker.
