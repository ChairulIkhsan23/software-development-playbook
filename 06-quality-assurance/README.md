# 06 - Quality Assurance

Modul ini menjelaskan strategi jaminan kualitas perangkat lunak secara holistik, piramida pengujian, desain test case, otomatisasi API dan E2E, serta kriteria Definition of Ready (DoR) dan Definition of Done (DoD).

## Dokumen dalam Modul Ini:
1. [Test Strategy](test-strategy.md) - Prinsip piramida pengujian dan matriks tanggung jawab.
2. [Unit Testing](unit-testing.md) - Pola AAA (Arrange-Act-Assert) dan isolasi dependensi.
3. [Integration Testing](integration-testing.md) - Pengujian interaksi komponen, database, dan service.
4. [End-to-End Testing](end-to-end-testing.md) - Otomatisasi pengujian alur pengguna dari browser/klien.
5. [API Testing](api-testing.md) - Uji kontrak, validasi skema payload, dan pengujian beban awal.
6. [Test Case Design](test-case-design.md) - Boundary Value Analysis dan Equivalence Partitioning.
7. [Acceptance Testing](acceptance-testing.md) - Uji penerimaan pengguna (UAT) dan sign-off bisnis.
8. [Regression Testing](regression-testing.md) - Strategi smoke test dan suite regresi otomatis.
9. [Bug Reporting](bug-reporting.md) - Struktur tiket bug yang dapat direproduksi secara cepat.
10. [Definition of Ready](definition-of-ready.md) - Kriteria item siap dikerjakan oleh developer.
11. [Definition of Done](definition-of-done.md) - Kriteria fitur siap dirilis ke produksi.
