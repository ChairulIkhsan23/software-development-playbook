# 00 - Foundations

Modul ini menetapkan pemahaman bersama (*shared mental model*) mengenai rekayasa perangkat lunak, siklus hidup pengembangan sistem, alur kolaborasi version control, dan glosarium istilah umum.

## Dokumen dalam Modul Ini:
1. [Software Development Lifecycle](software-development-lifecycle.md) - Model SDLC, fase standar, dan perbandingan metodologi.
2. [Software Engineering Principles](software-engineering-principles.md) - Prinsip fundamental (SOLID, DRY, KISS, YAGNI, Separation of Concerns).
3. [Git and GitHub Workflow](git-and-github-workflow.md) - Strategi branching, conventional commits, dan siklus PR review.
4. [Documentation Principles](documentation-principles.md) - Pendekatan Docs-as-Code, kejelasan teks, dan pemeliharaan dokumen hidup.
5. [Software Project Types](software-project-types.md) - Karakteristik aplikasi web, mobile, API service, tools internal, dan SaaS.
6. [Glossary](glossary.md) - Glosarium istilah baku dalam siklus rekayasa perangkat lunak.
