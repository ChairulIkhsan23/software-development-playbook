# Quality Checklists & Stage Gates

Kumpulan daftar periksa verifikasi kualitas untuk mengevaluasi kesiapan transisi antar-fase proyek software development.

## Daftar Checklist:
1. [Discovery Readiness](discovery-readiness.md) - Pintu gerbang keluar dari fase Discovery.
2. [PRD Quality](prd-quality.md) - Peninjauan kualitas dokumen spesifikasi produk.
3. [Requirements Quality](requirements-quality.md) - Verifikasi kelengkapan dan keterujian user stories & use cases.
4. [Pre-Development Readiness](pre-development-readiness.md) - Kesiapan sebelum sprint development dimulai (DoR).
5. [Security Review](security-review.md) - Audit pencegahan kerentanan OWASP dan proteksi data.
6. [Code Review](code-review.md) - Standar evaluasi kualitas pull request kode.
7. [Testing Readiness](testing-readiness.md) - Kesiapan lingkungan QA dan cakupan test cases.
8. [Release Readiness](release-readiness.md) - Verifikasi kelaikan rilis ke lingkungan produksi.
9. [Maintenance Review](maintenance-review.md) - Evaluasi berkala hutang teknis dan performa operasional.
