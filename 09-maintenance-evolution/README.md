# 09 - Maintenance and Evolution

Modul ini memandu pemeliharaan berkelanjutan sistem perangkat lunak pasca rilis produksi: pengelolaan hutang teknis (*tech debt*), pembaruan dependensi, review performa, dan evaluasi berkala metrik produk.

## Dokumen dalam Modul Ini:
1. [Technical Debt](technical-debt.md) - Identifikasi, kuadran hutang teknis, dan alokasi sprint refactoring.
2. [Dependency Updates](dependency-updates.md) - Jadwal pembaruan pustaka dan otomatisasi patching.
3. [Performance Review](performance-review.md) - Profiling bottleneck komputasi, kueri lambat, dan optimasi web vitals.
4. [Deprecation and Migration](deprecation-and-migration.md) - Strategi pensiun fitur lama dan panduan migrasi pengguna.
5. [Post-Release Review](post-release-review.md) - Retrospektif pasca peluncuran dan evaluasi pembelajaran tim.
6. [Product Metrics Review](product-metrics-review.md) - Evaluasi kesesuaian target metrik bisnis dan iterasi fitur.
