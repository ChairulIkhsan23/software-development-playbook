# 05 - Development Practices

Modul ini menetapkan standar operasional harian bagi software engineer: arsitektur repository, konvensi penulisan kode, alur review, manajemen konfigurasi, hingga proses orientasi pengembang baru.

## Dokumen dalam Modul Ini:
1. [Repository Structure](repository-structure.md) - Standar struktur direktori monorepo dan polyrepo.
2. [Coding Standards](coding-standards.md) - Linting, formatting, penamaan, dan penulisan komentar.
3. [Code Review](code-review.md) - Etika review, kriteria evaluasi PR, dan checklist reviewer.
4. [Branching and Commits](branching-and-commits.md) - Konvensi nama branch dan conventional commit message.
5. [Environment Configuration](environment-configuration.md) - Prinsip Twelve-Factor App dan manajemen file `.env`.
6. [Dependency Management](dependency-management.md) - SemVer, lockfiles, dan audit kerentanan keamanan.
7. [Logging and Error Handling](logging-and-error-handling.md) - Format log terstruktur (JSON), log levels, dan correlation ID.
8. [Developer Onboarding](developer-onboarding.md) - Panduan instalasi lokal, seed data, dan verifikasi kesiapan sistem.
